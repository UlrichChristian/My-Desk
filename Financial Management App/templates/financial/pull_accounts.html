Pull Accounts

Pull the current account list — lives, premium, advisor — from the EA admin site into a CSV that feeds the revenue reports.

What this does

  • Opens the EA admin site in Edge (you log in manually).
  • Queries the accounts API and pages through all clients (Active, Terminated, and Updating) — full field set, including advisor and consulting house.
  • Saves the result as a CSV for the Biggest Clients import.

Read-only — this only reads the accounts API; nothing on the admin site changes.

Process Street: mirror this pull with a to-do step and an audit step.

Run pull

Opens a new console window and an Edge browser. Log in to the EA admin site, make sure the accounts grid is showing, then press Enter in the console. The CSV is saved under uploads/ when the scrape finishes.
