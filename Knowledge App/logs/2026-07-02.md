## Retroactive time logging — new feature (MCP + web)
There was no built-in way to add time after the fact (only live start/stop). Built it end-to-end:
- **Service** (`Focus Board/focus_services/time_tracker.py`): `add_manual_entry`, `update_entry`,
  `delete_entry`, `get_entry`; `list_entries_for_task` now returns `id`. All timestamps UTC ISO;
  duration derived from start/end.
- **MCP** (`mcp/focus_mcp.py`): new `add_time_entry(task_id, date, start, end, tz="America/Edmonton",
  confirmed)`. Accepts local wall-clock ("09:00" or "9:00 AM"), converts to UTC via zoneinfo
  (DST-aware — verified 9AM→15:00Z in July, 16:00Z in January). Confirm-gated; preview shows
  resolved UTC range + minutes.
- **Web** (`focus_web/routes.py` + `templates/focus/task_form.html` + `static/focus/focus.css`):
  a "Time log" card on the task **edit** page (shows for completed tasks too) — history of entries
  with inline edit/delete + a manual add form. Endpoints: GET `/focus/task/<id>/time`,
  POST `/focus/task/<id>/time/add`, POST `/focus/time/<eid>/edit`, POST `/focus/time/<eid>/delete`.
  All UTC↔local conversion is done client-side in the browser (codebase has no server tz handling).
Verified at every layer (service, MCP tool, JSON routes incl. 400/404, edit-page render).
