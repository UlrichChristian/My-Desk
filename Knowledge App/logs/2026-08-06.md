## 13:59 — My Desk / ASO cross-login bug fixed
**Symptom:** logging into My Desk (:5002) logged you out of the ASO app (:5000), and vice versa.

**Cause:** browser cookies are scoped by *host*, not host+port. `127.0.0.1:5002` and `127.0.0.1:5000` share one cookie jar. Both apps used Flask's default cookie name `session` but different signing keys (`C_APP_SECRET_KEY` vs `ASO_SECRET_KEY`), so each app overwrote the other's cookie and then failed the signature check — Flask silently discards an unverifiable session cookie and shows the login page.

**Fix:** set `SESSION_COOKIE_NAME = "cdesk_session"` in `c.py` `create_app()`. Only one side needs a distinct name; ASO keeps `session`. Verified with the Flask test client: My Desk now issues only `cdesk_session`.

**Known, accepted:** `c.py:38` falls back to `os.urandom(32)` when `C_APP_SECRET_KEY` is unset, so My Desk mints a new signing key on every restart and logs you out. There is no `.env` in `C:/Christian` and nothing loads dotenv. ASO has a `.env` with `ASO_SECRET_KEY`, which is why only My Desk lost sessions on restart. Christian decided not to fix this — the restart logout is acceptable for a local single-user app. Don't re-raise it. (If it ever matters, the fix is to persist a generated key to a gitignored file on first run.)
