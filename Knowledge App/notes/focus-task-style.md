# Task title and description style guide for My Desk productivity captures.
# Edit this note over time — the MCP suggest_task_wording tool reads it.
> Verb-first titles, clear context in notes, no vague placeholders.

## Title rules
- Start with a strong verb or deliverable noun (Email, Reconcile, Review, Build).
- Keep titles under 80 characters.
- Use title case for proper nouns; sentence case for generic tasks.
- Avoid: TODO, TBD, stuff, thing, fix it, misc.

## Description / notes
- One line of context: why, who, or blocker.
- Include dates, amounts, or ticket refs when relevant.
- Email captures: paste the ask + your intended next action.

## Examples
- Good: **Email HUB re ISL transition**
- Bad: **ISL stuff**
- Good notes: "HUB asked for division split confirmation by Friday. Reply with EA/ED breakdown."
